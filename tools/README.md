# 갱신보험료 납입 엑셀 인쇄용 서식 정리 도구

월별 갱신보험료 납입 엑셀(`.xlsx`)을 **출력용으로 보기 좋게** 정리합니다.
값과 수식은 건드리지 않고 **서식만** 바꿉니다.

## 적용되는 서식

| 항목 | 처리 내용 |
|---|---|
| 1행 제목 | 밝은 하늘색 배경(`#D9E8F7`) + 진남색 굵은 글씨 + 가운데 정렬, 행 높이 30 |
| 본문 전체 | 가로·세로 가운데 정렬, 맑은 고딕 10pt |
| 금액 숫자 | **오른쪽 정렬 유지** (1,000 이상이거나 `#,##0`·통화 서식인 셀, `"USD 5,000"` 같은 문자열 금액 포함) |
| 날짜 / 회차 / % | 가운데 정렬 (금액으로 오인되지 않도록 분리) |
| 테두리 | 연회색 얇은 선(`#BFCEE0`) |
| 열 너비 | 내용 기준 자동 (한글·한자는 2칸으로 계산, 최소 8 / 최대 42) |
| 보기 | 눈금선 끔, 1행 틀 고정 |
| 인쇄 | A4 가로, 너비 1페이지 맞춤, 1행 제목 반복, 좌우 가운데, 여백 축소 |

## 1. Python 버전 — `format_renewal_xlsx.py`

폴더 안 `.xlsx`를 한 번에 처리합니다.

```bash
pip install openpyxl

# 폴더 전체
python tools/format_renewal_xlsx.py "C:\Users\dingg\OneDrive\바탕 화면\갱신보험료 납입"

# 원본 백업(.xlsx.bak)을 남기면서 처리 — 처음 돌릴 때 권장
python tools/format_renewal_xlsx.py "…\갱신보험료 납입" --backup

# 파일 하나만
python tools/format_renewal_xlsx.py "…\갱신보험료 납입\2026.09.xlsx"
```

옵션

| 옵션 | 설명 |
|---|---|
| `--backup` | 원본을 `파일명.xlsx.bak` 으로 백업 후 처리 |
| `--recursive` | 하위 폴더까지 처리 |
| `--comma` | 제목에 `금액·보험료·합계` 등이 들어간 열의 General 서식 숫자에 1,000 단위 콤마 부여 |
| `--orientation portrait` | 인쇄 방향 세로 (기본 `landscape`) |

파일 하나가 실패해도 나머지는 계속 처리하고, 마지막에 실패 목록을 출력합니다.

## 2. VBA 버전 — `FormatRenewalSheets.bas`

Python 설치 없이 엑셀에서 바로 실행하는 방식입니다.

1. 엑셀 열기 → `Alt` + `F11` (VBA 편집기)
2. `[파일] > [파일 가져오기]` 로 `FormatRenewalSheets.bas` 가져오기
   (또는 `[삽입] > [모듈]` 후 파일 내용 전체 복사·붙여넣기)
3. `Alt` + `F8` 로 매크로 실행
   - `FormatActiveWorkbook` — 지금 열려 있는 파일만 정리
   - `FormatFolder` — 폴더를 선택해 `.xlsx` 전체 일괄 정리

## 주의

- 일괄 실행은 **원본을 덮어씁니다.** 되돌리기가 안 되므로 첫 실행은 `--backup` 을 쓰거나 폴더를 통째로 복사해 두고 진행하세요.
- 병합 셀이 많거나 소계 행이 섞인 시트는 자동 열 너비가 어색할 수 있습니다. 실행 후 한 번 확인하고 필요하면 해당 열만 손보시면 됩니다.
- 결과물은 초안 기준입니다. 출력 전 육안 검수를 권장합니다.
