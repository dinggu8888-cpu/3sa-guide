# 갱신보험료 납입 엑셀 인쇄용 서식 정리 도구

월별 갱신보험료 납입 엑셀(`.xlsx`)을 **출력용으로 보기 좋게** 정리합니다.
값과 수식은 건드리지 않고 **서식만** 바꿉니다.

## 적용되는 서식

| 항목 | 처리 내용 |
|---|---|
| 1행 제목 | 밝은 하늘색 배경(`#D9E8F7`) + 진남색 굵은 글씨 + 가운데 정렬, 행 높이 30 |
| 본문 전체 | 가로·세로 가운데 정렬, 맑은 고딕 10pt |
| 금액 열 | **오른쪽 정렬** — 제목에 `Premium·Levy·Loan·USD·금액·보험료` 등이 들어간 열 전체 (값이 `0`이어도 유지) |
| 식별번호 열 | 가운데 정렬 — 제목에 `Policy no.·증권·번호·N차년` 등이 들어가면 숫자여도 금액으로 보지 않음 |
| 날짜 / % | 가운데 정렬 |
| 금액 표시 서식 | 한 열 안에 `#,##0.00`·`General` 이 섞여 있으면 우세한 쪽으로 통일. 서식이 아예 없는 금액 열은 같은 시트의 다른 금액 열을 따름 |
| 기입용 빈 칸 | 제목만 있고 값이 없는 열(예: `송금일`)은 기존 너비를 줄이지 않음 |
| 테두리 | 연회색 얇은 선(`#BFCEE0`) |
| 열 너비 | 내용 기준 자동 (한글·한자는 2칸으로 계산, 최소 8 / 최대 42) |
| 보기 | 눈금선 끔, 1행 틀 고정 |
| 인쇄 | A4 가로, 너비 1페이지 맞춤, 1행 제목 반복, 좌우 가운데, 여백 축소 |

## 어느 스크립트를 쓸 것인가

| 상황 | 스크립트 |
|---|---|
| **10월 이후 파일을 2026.09 파일과 똑같이 맞추고 싶다** | `match_september_style.py` |
| 기준 파일이 따로 없고, 인쇄용으로 새로 정리하고 싶다 | `format_renewal_xlsx.py` |

## 0. 9월 서식 맞추기 — `match_september_style.py`

2026.09 파일을 기준으로 삼아 나머지 달 파일을 같은 모양으로 통일합니다.
9월과 달라지는 점은 **금액 열 우측 정렬** 하나뿐입니다.

```bash
# 기준 파일에서 열 너비를 직접 읽어서 적용 (권장)
python tools/match_september_style.py "…\갱신보험료 납입" --reference "…\2026.09.xlsx" --backup

# 파일 하나만
python tools/match_september_style.py "2026.11.xlsx" --reference "2026.09.xlsx"
```

적용 서식 (2026.09 파일에서 추출한 값):

| 항목 | 값 |
|---|---|
| 제목행 | Calibri Light 11, 굵게 아님, 배경 `F8CBAD`(살구색), 가운데 |
| 본문 | Calibri 11, 가로·세로 가운데 |
| 테두리 | 전 셀 얇은 선 |
| 금액 열 | 우측 정렬 + `#,##0.00` — 제목에 `Premium·Levy·Loan·FPD·USD·금액·보험료` 등이 들어간 열 |
| 식별번호 열 | 가운데 — `Policy no.·증권·번호·N차년` 등은 숫자여도 금액으로 보지 않음 |
| 열 너비 | 제목 이름으로 매칭해 적용 (열 순서·개수가 달라도 안전). 기준 파일이 폭을 지정하지 않은 열은 지정을 지워 엑셀 기본값으로 되돌림 |
| 인쇄 | 가로 |
| 틀고정·눈금선 | 설정하지 않음 (9월 파일과 동일하게 기본값 유지) |

`--reference` 를 주면 내장된 기준값 대신 그 파일의 실제 열 너비를 읽어 씁니다.
폴더를 대상으로 하면 기준 파일 자신은 처리 대상에서 빠집니다.

### 검증 (2026.10 · 2026.11 실제 파일)

`renewal_generator.py` 가 뽑은 10·11월 파일은 **제목행 배경색이 아예 없고 본문 정렬이 지정되지 않은** 상태였습니다
(제목행 맑은 고딕 굵게, 본문 정렬 `None`). 9월 파일은 생성기가 완성되기 전에 만들어진 것이라 서식이 달랐습니다.

`--reference` 로 9월 파일을 물려 실행한 결과:

| 항목 | 10월 | 11월 |
|---|---|---|
| 제목행 배경 `F8CBAD` / 글꼴 / 정렬 | 일치 | 일치 |
| 본문 글꼴 · 가로세로 가운데 · 테두리 | 일치 | 일치 |
| 열 너비 8개 · 인쇄 방향 | 일치 | 일치 |
| 금액 3열(`Premium + Levy`·`FPD`·`APL Loan`) 우측 정렬 | 적용 | 적용 |
| 셀 값 전수 비교 | 차이 0건 (23건) | 차이 0건 (25건) |

> 일괄 실행은 원본을 덮어씁니다. 첫 실행은 `--backup` 을 붙여 주세요.

## 1. 인쇄용 새로 정리 — `format_renewal_xlsx.py`

폴더 안 `.xlsx`를 한 번에 처리합니다.

```bash
pip install openpyxl

# 폴더 전체
python tools/format_renewal_xlsx.py "C:\Users\dingg\OneDrive\바탕 화면\갱신보험료 납입"

# 원본 백업(.xlsx.bak)을 남기면서 처리 — 처음 돌릴 때 권장
python tools/format_renewal_xlsx.py "…\갱신보험료 납입" --backup

# 파일 하나만
python tools/format_renewal_xlsx.py "…\갱신보험료 납입\2026.09.xlsx"
```

옵션

| 옵션 | 설명 |
|---|---|
| `--backup` | 원본을 `파일명.xlsx.bak` 으로 백업 후 처리 |
| `--recursive` | 하위 폴더까지 처리 |
| `--comma` | 제목에 `금액·보험료·합계` 등이 들어간 열의 General 서식 숫자에 1,000 단위 콤마 부여 |
| `--orientation portrait` | 인쇄 방향 세로 (기본 `landscape`) |
| `--right-cols "G,I,J"` | 자동 판정을 무시하고 해당 열을 오른쪽 정렬 |
| `--center-cols "C,D"` | 자동 판정을 무시하고 해당 열을 가운데 정렬 |

열 자동 판정이 어긋나는 달이 있으면 `--right-cols` / `--center-cols` 로 직접 잡아주면 됩니다.

### 실제 적용 예 (2026.09 파일)

12개 열 / 31개 행 기준으로 옵션 없이 기본 실행했을 때의 판정 결과입니다.

| 열 | 제목 | 판정 |
|---|---|---|
| C | `Policy no.` | 가운데 — 숫자형 증권번호를 금액으로 보지 않음 |
| D | `N차년` | 가운데 |
| G | `Premium + Levy (USD)` | 오른쪽, `#,##0.00` |
| H | `Paid to date` | 가운데 (`12/09/2026` 문자열 날짜) |
| I | `FPD (USD)` | 오른쪽, 섞여 있던 서식을 `#,##0.00` 로 통일 |
| J | `APL Loan` | 오른쪽, 값이 전부 `0` 이라 다른 금액 열의 `#,##0.00` 을 상속 |
| L | `송금일` | 가운데, 빈 기입 칸이라 기존 너비(15.6) 유지 |

파일 하나가 실패해도 나머지는 계속 처리하고, 마지막에 실패 목록을 출력합니다.

## 2. VBA 버전 — `FormatRenewalSheets.bas`

Python 설치 없이 엑셀에서 바로 실행하는 방식입니다.

1. 엑셀 열기 → `Alt` + `F11` (VBA 편집기)
2. `[파일] > [파일 가져오기]` 로 `FormatRenewalSheets.bas` 가져오기
   (또는 `[삽입] > [모듈]` 후 파일 내용 전체 복사·붙여넣기)
3. `Alt` + `F8` 로 매크로 실행
   - `FormatActiveWorkbook` — 지금 열려 있는 파일만 정리
   - `FormatFolder` — 폴더를 선택해 `.xlsx` 전체 일괄 정리

## 고객정보 주의

실제 납입 파일에는 계약자·피보험자 실명이 들어 있습니다. **저장소에 커밋하지 마세요.**
루트 `.gitignore` 에서 `*.xlsx` 를 제외해 두었습니다.

## 주의

- 일괄 실행은 **원본을 덮어씁니다.** 되돌리기가 안 되므로 첫 실행은 `--backup` 을 쓰거나 폴더를 통째로 복사해 두고 진행하세요.
- 병합 셀이 많거나 소계 행이 섞인 시트는 자동 열 너비가 어색할 수 있습니다. 실행 후 한 번 확인하고 필요하면 해당 열만 손보시면 됩니다.
- 결과물은 초안 기준입니다. 출력 전 육안 검수를 권장합니다.

## 근본 원인과 생성기 수정 (2026-09-29)

월별 파일은 사용자 PC의 `renewal_generator.py` 가 매일 자동 생성한다.
10월 이후 파일의 서식이 빈약했던 것은 이 스크립트의 `generate_excel()` 에
서식 지정이 거의 없었기 때문이다. 2026.09 파일은 이 스크립트가 완성되기 전에
만들어져서 서식이 달랐다.

수정 전:

```python
header_font = Font(bold=True)               # 글꼴명 없음 → 테마 글꼴(맑은 고딕) 굵게
cell.alignment = Alignment(horizontal="center")   # 제목행만. 배경색 없음
# 본문 셀에는 테두리만 지정. 글꼴·정렬 지정 자체가 없음
col_widths = [10, 12, 16, 8, 20, 20, 22, 14, 12, 10, 10, 10]
```

수정 후 (2026.09 기준 + 금액 열 우측 정렬):

```python
header_font = Font(name="Calibri Light", size=11, bold=False)
header_fill = PatternFill("solid", fgColor="FFF8CBAD")
body_font   = Font(name="Calibri", size=11)
center = Alignment(horizontal="center", vertical="center")
right  = Alignment(horizontal="right",  vertical="center")

MONEY_COLS = {7, 9, 10}      # Premium + Levy · FPD · APL Loan

# 본문: 금액 열은 right + '#,##0.00', 나머지는 center
# 열 너비는 2026.09 가 지정한 열만
col_widths = {1: 9.0, 3: 12.875, 4: 9.0, 5: 19.5,
              7: 15.75, 8: 12.875, 9: 9.0, 12: 15.625}
ws.page_setup.orientation = "landscape"
```

491행 중 35행 변경. 메일 수신·표 파싱·담당자/N차년 매핑·중복 방지 로직은 건드리지 않았다.

검증: 수정한 `generate_excel()` 을 가상 데이터(`TEST ALPHA` 등, 실명 아님)로 직접 실행해
2026.09 파일과 비교했다. 제목행 글꼴·배경·정렬, 본문 글꼴·정렬·테두리, 열 너비 8개,
인쇄 방향이 모두 일치했고 금액 3열에 우측 정렬과 `#,##0.00` 이 적용됐다.

> 스크립트 자체는 내부 폴더 경로와 업무용 메일 주소를 담고 있어 이 저장소에 두지 않는다.
